# Duroos-ul-Lughah Notes

Next.js landing page for Duroos-ul-Lughah English notes, with a Web3Forms lead form.

```bash
npm install
cp .env.example .env.local   # optional: set WhatsApp number / email
npm run dev
```

Env vars: `NEXT_PUBLIC_WEB3FORMS_KEY`, `NEXT_PUBLIC_WHATSAPP_NUMBER` (digits with country code), `NEXT_PUBLIC_CONTACT_EMAIL`.
